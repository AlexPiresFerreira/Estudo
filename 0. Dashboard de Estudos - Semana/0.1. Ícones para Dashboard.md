# Ícones para Dashboard

Use estes ícones para organizar seu dashboard de estudos, metas e progresso.

---

## 1. Status

- 🟢 = concluído / ok
- 🟡 = em andamento
- 🔴 = pendente / atenção
- 🔵 = informação / destaque
- ⚪ = não iniciado
- ✅ = feito
- ❌ = não feito
- ⏳ = aguardando
- 🔁 = recorrente
- ⚠️ = atenção

---

## 2. Estudo

- 📚 = livros
- 📖 = leitura
- 📝 = anotações
- ✏️ = escrita / revisão
- 🧠 = aprendizado
- 🎓 = curso
- 👨‍🏫 = aula / professor
- 💡 = ideia / insight
- 🔍 = pesquisa
- 📌 = ponto importante

---

## 3. Evolução e metas

- 📈 = progresso / crescimento
- 📉 = queda / redução
- 🎯 = meta
- 🏆 = objetivo alcançado
- ⭐ = destaque
- 📊 = relatório / métricas
- 🥇 = melhor resultado
- 🔥 = alto desempenho
- 🚀 = avanço rápido

---

## 4. Organização

- 📅 = calendário / data
- ⏰ = horário / lembrete
- 📋 = lista
- 🗂️ = arquivos / pastas
- 🗓️ = agenda
- 📎 = anexo / vínculo
- 🔖 = marcação / favorito
- 🗃️ = arquivo guardado
- 📥 = entrada / inbox
- 📤 = saída / enviado

---

## 5. Tarefas

- ☑️ = tarefa concluída
- ☐ = tarefa aberta
- 🔄 = tarefa em revisão
- 🧩 = tarefa parte de um projeto
- 🚧 = em construção
- ✅ = finalizado
- ❗ = prioridade
- 📍 = tarefa importante
- 🧭 = direção / próximo passo

---

## 6. Exemplo de uso no dashboard

### Resumo semanal
- 🎯 Meta: 200 páginas
- 📈 Progresso: 135 páginas
- 🟡 Status: em andamento
- ✅ Concluído: 3 aulas
- ⏳ Pendências: 2 aulas

### Leitura
- 📚 Livro 1
- 📖 Livro 2
- 📝 Resumo da leitura

### Cursos
- 🎓 Curso de Excel
- 🎓 Curso de Inglês
- 🧠 Revisão do conteúdo

---

## 7. Combinações úteis

- 🎯 + 📈 = meta e progresso
- 🟡 + ⏳ = em andamento / aguardando
- 📚 + ✅ = livro concluído
- 🎓 + 🧠 = curso em estudo
- 📊 + 🏆 = resultado final
- 📝 + 🔖 = nota importante
- 📅 + ⏰ = compromisso com horário

---

## 8. Sugestão de padrão visual

Use sempre a mesma lógica:

- **Verde** = concluído
- **Amarelo** = em andamento
- **Vermelho** = atenção
- **Azul** = informação
- **Ícone de livro** = leitura
- **Ícone de gráfico** = evolução
- **Ícone de alvo** = meta
